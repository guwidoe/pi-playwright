# Contributing

Thanks for your interest in improving `pi-playwright`.

## Issues and pull requests

- Bug reports and feature requests: https://github.com/guwidoe/pi-playwright/issues
- Pull requests are welcome: https://github.com/guwidoe/pi-playwright/pulls

## Local development

```bash
git clone https://github.com/guwidoe/pi-playwright.git
cd pi-playwright
npm install
npm run setup
npm test
npm run smoke
```

To try the local checkout with pi:

```bash
pi install .
```

## Notes for maintainers

Publishing new versions is maintainer-only and requires npm access to the package.
